Unit 1: Relevance of Mathematics in Computers

Why Do We Need Maths for Computers?

Think of a computer as a very fast calculator. Everything a computer does - from showing this page on your screen to sending a WhatsApp message - is done using mathematics. Without maths, computers simply cannot work! Just like you need a language to talk to people, computers need mathematics to understand and process information.

Key Concepts

1. Algorithms: An algorithm is a step-by-step procedure to solve a problem. Maths helps us write correct and efficient algorithms. For example, Google uses mathematical algorithms to find the best search results for you.

2. Data Structures: How data is stored and organized in a computer. Trees, graphs, and arrays all come from mathematics (especially set theory and graph theory).

3. Cryptography: Keeping data secure online (like your bank details) uses number theory and prime numbers. When you see "https" in a website URL, maths is protecting your data!

4. Computer Graphics: Every image, video game, and animation you see on screen uses coordinate geometry, vectors, and matrices to draw and move objects.

5. Database Management: Set theory (union, intersection) is the basis of SQL queries that retrieve data from databases.

6. Artificial Intelligence: Machine learning and AI use matrices, probability, and calculus to "learn" from data.

7. Logic and Circuits: Boolean algebra (mathematical logic) is used to design every digital circuit inside your computer and phone.

Unit 2: Set Theory

What is a Set? (Simple Explanation)

A set is simply a collection of distinct (different) things. Think of it like a bag where you put items - but you never put the same item twice! For example, a set of fruits = {apple, mango, banana}. If you have a box of crayons, that's a set of colors. Each item in a set is called an element or member.

Key Concepts

1. Notation: Sets are written with curly braces { }. Capital letters name the set, small letters name elements.

A = {1, 2, 3, 4, 5} means "Set A contains the numbers 1, 2, 3, 4, and 5"

2. Element check: We use the symbol ∈ (belongs to) and ∉ (does not belong to).

If A = {1, 2, 3}, then 2 ∈ A (2 belongs to A) and 7 ∉ A (7 does not belong to A)

3. Types of Sets:

  • Empty Set (Null Set) ∅: A set with no elements. Example: Set of even prime numbers greater than 2 = { } = ∅
  • Singleton Set: A set with exactly one element. Example: {7}
  • Finite Set: A set with a countable number of elements. Example: {a, b, c}
  • Infinite Set: A set with uncountable elements. Example: Set of natural numbers = {1, 2, 3, ...}
  • Universal Set (U): The big set that contains everything we are talking about. Example: If discussing students in a class, U = all students in the class.
  • Subset (⊆): Set A is a subset of B if EVERY element of A is also in B. Example: A = {1, 2}, B = {1, 2, 3, 4} → A ⊆ B
  • Proper Subset (⊂): A is a proper subset of B if A is a subset of B but A ≠ B (A is smaller than B).
  • Superset: If A ⊆ B, then B is the superset of A.
  • Power Set P(A): The set of ALL possible subsets of A. If A has n elements, the power set has 2n elements.
If A = {1, 2}, then P(A) = {{}, {1}, {2}, {1,2}} → 2² = 4 subsets

4. Set Operations:

  • Union (A∪B): All elements that are in A OR in B (or both). Think: "Combine everything"
  • Intersection (A∩B): Elements that are in BOTH A and B. Think: "Common elements"
  • Difference (A-B): Elements in A but NOT in B. Think: "A minus B's elements"
  • Complement (A'): Elements in U but NOT in A. Think: "Everything except A"
Let A = {1, 2, 3, 4}, B = {3, 4, 5, 6}, U = {1, 2, 3, 4, 5, 6, 7, 8}
A∪B = {1, 2, 3, 4, 5, 6} (all elements from both)
A∩B = {3, 4} (common elements)
A-B = {1, 2} (in A but not in B)
A' = {5, 6, 7, 8} (in U but not in A)

5. Venn Diagrams: Pictures that show sets as circles. Union is the total shaded area, intersection is the overlapping area.

6. De Morgan's Laws (VERY IMPORTANT):

  • (A∪B)' = A'∩B'    (Complement of union = Intersection of complements)
  • (A∩B)' = A'∪B'    (Complement of intersection = Union of complements)

7. Laws of Set Theory:

  • Commutative: A∪B = B∪A and A∩B = B∩A
  • Associative: (A∪B)∪C = A∪(B∪C) and (A∩B)∩C = A∩(B∩C)
  • Distributive: A∪(B∩C) = (A∪B)∩(A∪C) and A∩(B∪C) = (A∩B)∪(A∩C)
  • Idempotent: A∪A = A and A∩A = A

Important Formulas

1. Number of subsets: If a set has n elements, it has 2n subsets.

2. Number of proper subsets: 2n - 1

3. Cardinality of Union: |A∪B| = |A| + |B| - |A∩B|

4. For three sets: |A∪B∪C| = |A| + |B| + |C| - |A∩B| - |B∩C| - |A∩C| + |A∩B∩C|

Example: If A = {1,2,3,4,5} and B = {3,4,5,6,7}, find |A∪B|
|A| = 5, |B| = 5, |A∩B| = |{3,4,5}| = 3
|A∪B| = 5 + 5 - 3 = 7 → A∪B = {1,2,3,4,5,6,7} ✓

The symbol ∅ denotes the empty set with no elements.

Unit 3: Mathematical Induction

What is Mathematical Induction? (Simple Explanation)

Imagine you have a row of dominoes standing up. If you push the first domino, it falls and knocks down the second, which knocks down the third, and so on - ALL dominoes fall! Mathematical induction works exactly like this. You prove something is true for the first case, then show that if it's true for any case, it must also be true for the next case. This proves it's true for ALL cases!

Key Concepts

Mathematical Induction is a method to prove that a statement is true for all natural numbers (1, 2, 3, 4, ...).

It has two steps:

Step 1 - Base Case: Show the statement is true for n = 1 (or the first value).

Step 2 - Inductive Step: Assume the statement is true for n = k (this is called the "induction hypothesis"). Then prove it is also true for n = k + 1.

If both steps succeed, the statement is true for ALL natural numbers!

Important Formulas and Examples

Example 1: Prove that 1 + 2 + 3 + ... + n = n(n+1)/2

Step 1 (Base Case): For n = 1: LHS = 1, RHS = 1(1+1)/2 = 2/2 = 1. LHS = RHS. ✓
Step 2 (Inductive Step): Assume true for n = k: 1 + 2 + ... + k = k(k+1)/2 ... (i)
Now prove for n = k+1: LHS = 1 + 2 + ... + k + (k+1)
= k(k+1)/2 + (k+1)    [using (i)]
= [k(k+1) + 2(k+1)] / 2
= (k+1)(k+2) / 2
= (k+1)((k+1)+1) / 2 = RHS for n = k+1. ✓

Hence, by mathematical induction, the formula is true for all natural numbers.

Example 2: Prove that 2n > n for all natural numbers

Step 1: For n = 1: 21 = 2 > 1. ✓
Step 2: Assume 2k > k ... (i)
For n = k+1: 2k+1 = 2 × 2k > 2 × k = 2k [from (i)]
Since k ≥ 1, we have 2k ≥ k + 1. Therefore 2k+1 > k + 1. ✓

What to Write in Exam

It has two steps: (1) Base case - verify the statement for n = 1, (2) Inductive step - assume it's true for n = k, then prove for n = k + 1. If both steps are verified, the statement is true for all n.

For 5 marks - Explain the steps of mathematical induction: Mathematical induction works like falling dominoes. Step 1 (Base Case): Prove P(1) is true. Step 2 (Inductive Step): Assume P(k) is true (induction hypothesis), then prove P(k+1) is also true. The principle is: if P(1) is true, and P(k) → P(k+1), then P(n) is true for all n ∈ N. This works because truth propagates from 1 to 2, 2 to 3, and so on infinitely.

For 10 marks - Prove using mathematical induction: Write the full proof as shown in the formula box above with clear Step 1 and Step 2. Always state the conclusion: "Hence, by the principle of mathematical induction, the statement is true for all natural numbers n."

Memory Trick

"BAIL" - Base case first, Assume for k, Increase to k+1, Link them together!

Think of it like a ladder: First you stand on the first rung (base case), then you show that if you can stand on any rung k, you can also reach rung k+1 (inductive step). This means you can climb the entire infinite ladder!

Unit 4: Exponents, Logarithms and Surds

What are Exponents, Logarithms and Surds?

Exponent is a short way to write repeated multiplication. Instead of writing 2 × 2 × 2, we write 2³ = 8. The small number on top tells you how many times to multiply the base by itself.

Logarithm is the REVERSE of exponents! If 2³ = 8, then log28 = 3 (the exponent you need). Logarithm asks: "What power do I need to raise the base to, to get this number?"

Surds are square roots (or cube roots etc.) that cannot be simplified to a whole number or simple fraction. Like √2 = 1.41421356... (never ends!). Surds are irrational numbers left in root form.

Key Concepts

Laws of Exponents:

  • am × an = am+n    (same base, add exponents)
  • am ÷ an = am-n    (same base, subtract exponents)
  • (am)n = am×n    (power of power, multiply exponents)
  • (a × b)n = an × bn    (distribute over multiplication)
  • a0 = 1    (anything to power 0 equals 1)
  • a-n = 1/an    (negative exponent = reciprocal)
2³ × 2&sup4; = 27 = 128   |   56/5² = 54 = 625   |   (3²)³ = 36 = 729   |   100 = 1   |   2-3 = 1/2³ = 1/8

Laws of Logarithms:

  • loga(M × N) = logaM + logaN    (Product rule)
  • loga(M ÷ N) = logaM - logaN    (Quotient rule)
  • loga(Mn) = n × logaM    (Power rule)
  • logaa = 1    (log of same base = 1)
  • loga1 = 0    (log of 1 = 0)
  • logaan = n    (log and exponent cancel)
log(100) = log(10²) = 2   |   log28 = log22³ = 3   |   log525 = 2

Common Log (base 10): Written as "log" without base. Used in science and engineering.

Natural Log (base e): Written as "ln". Here e ≈ 2.718. Used in calculus.

Surds:

  • √a × √b = √(a×b)
  • √a ÷ √b = √(a÷b)
  • Rationalize: √a/√b = (√a × √b) / b
Simplify √50 = √(25 × 2) = 5√2   |   Rationalize 1/√3 = √3/3

Important Formulas

Change of Base Formula: logab = logcb / logca

Most useful: logab = log b / log a (using common log)

log381 = log 81 / log 3 = 4 log 3 / log 3 = 4

What to Write in Exam

For 3 marks - Laws of exponents: The laws are: (1) am×an = am+n, (2) am/an = am-n, (3) (am)n = amn, (4) a0 = 1, (5) a-n = 1/an. Example: 2³×2&sup4; = 27 = 128.

For 5 marks - Laws of logarithms with examples: (1) Product rule: log(MN) = log M + log N. Example: log(100×1000) = log 100 + log 1000 = 2 + 3 = 5. (2) Quotient rule: log(M/N) = log M - log N. Example: log(1000/10) = 3 - 1 = 2. (3) Power rule: log(Mn) = n log M. Example: log(25) = 5 log 2. (4) loga1 = 0, (5) logaa = 1.

For 10 marks - Explain exponents, logarithms, and surds with solved examples: Cover all three topics with definitions, laws, and 2-3 solved numerical examples for each.

Memory Trick

Exponents: "Multiply the base, ADD the powers" for same base multiplication.

Logarithms: "Log turns MULTIPLICATION into ADDITION, DIVISION into SUBTRACTION!" This is the whole point of logarithms - they simplify hard calculations.

Remember: a0 = 1 (anything to power 0 is 1) and log 1 = 0 (log of 1 is always 0).

Surds: "Pull out PAIRS from under the root" - √50 = √(25×2) = 5√2 (25 = 5², pulled out 5).

Unit Summary (Quick Revision)

  • Exponent = repeated multiplication: an = a × a × ... (n times)
  • Key exponent rules: multiply → add powers, divide → subtract powers
  • a0 = 1, a-n = 1/an
  • Logarithm is the reverse of exponent: if ax = N, then logaN = x
  • log(MN) = log M + log N, log(M/N) = log M - log N, log(Mn) = n log M
  • Common log = base 10, Natural log = base e
  • Surds are irrational roots: √2, √3, ³√5 etc.
  • Rationalize surds by multiplying numerator and denominator by the surd

Unit 5: Number Systems

What is a Number System?

A number system is a way of writing numbers using different bases. We normally use base 10 (decimal) because we have 10 fingers. But computers only understand 0 and 1, so they use base 2 (binary). There are also base 8 (octal) and base 16 (hexadecimal) which are shortcuts for writing binary numbers.

Key Concepts

SystemBaseDigits UsedExample
Decimal100,1,2,3,4,5,6,7,8,9255
Binary20,111111111
Octal80,1,2,3,4,5,6,7377
Hexadecimal160-9, A(10),B(11),C(12),D(13),E(14),F(15)FF

Conversion Methods:

1. Decimal to Binary: Keep dividing by 2, write remainders from bottom to top.

Convert 13 to binary:
13 ÷ 2 = 6 remainder 1
6 ÷ 2 = 3 remainder 0
3 ÷ 2 = 1 remainder 1
1 ÷ 2 = 0 remainder 1
Read remainders bottom to top: 1101

2. Binary to Decimal: Multiply each digit by its power of 2 (from right, starting at 20).

Convert 1101 to decimal:
1×2³ + 1×2² + 0×2¹ + 1×2&sup0; = 8 + 4 + 0 + 1 = 13

3. Binary to Octal: Group binary digits in sets of 3 from right, convert each group.

110101 → 110 | 101 → 6 | 5 → 65 (octal)

4. Binary to Hexadecimal: Group binary digits in sets of 4 from right, convert each group.

11010111 → 1101 | 0111 → D | 7 → D7 (hex)

5. Octal to Binary: Replace each octal digit with its 3-bit binary equivalent.

65 (octal) → 6=110, 5=101 → 110101 (binary)

6. Hexadecimal to Binary: Replace each hex digit with its 4-bit binary equivalent.

A3 (hex) → A=1010, 3=0011 → 10100011 (binary)

7. 1's Complement: Flip all bits (0→1, 1→0).

1's complement of 10110 = 01001

8. 2's Complement: 1's complement + 1. Used to represent negative numbers in computers.

2's complement of 10110 = 01001 + 1 = 01010

Important Formulas

Decimal to any base b: Repeatedly divide by b, collect remainders bottom to top.

Any base to Decimal: Multiply each digit by baseposition and add.

Binary ↔ Octal: Group/expand in 3 bits

Binary ↔ Hex: Group/expand in 4 bits

2's Complement: = 1's complement + 1

Unit 6: Permutations and Combinations

What are Permutations and Combinations?

Permutation = Arrangement where ORDER MATTERS. Example: A password "123" is different from "321" - order matters!

Combination = Selection where ORDER DOES NOT MATTER. Example: Choosing 3 friends from 5 to form a team - the order you pick them doesn't matter, the team is the same.

Key Concepts

Factorial (n!): The product of all positive integers up to n.

5! = 5 × 4 × 3 × 2 × 1 = 120   |   0! = 1   |   1! = 1

Permutation Formula:

nPr = n! / (n-r)!

This counts: "How many ways to ARRANGE r items from n items?"

How many ways to arrange 3 books from 5 books on a shelf?
5P3 = 5!/(5-3)! = 5!/2! = (5×4×3×2×1)/(2×1) = 120/2 = 60 ways

Combination Formula:

nCr = n! / [r! × (n-r)!]

This counts: "How many ways to SELECT r items from n items?"

How many ways to choose 3 students from 5 for a committee?
5C3 = 5!/[3!×(5-3)!] = 120/[6×2] = 120/12 = 10 ways

Key Difference:

PermutationCombination
Order mattersOrder does NOT matter
ArrangementSelection
AB ≠ BAAB = BA (same group)
Password, seating arrangementTeam selection, lottery
nPr = n!/(n-r)!nCr = n!/[r!(n-r)!]

Important Relations:

  • nCr = nCn-r   (e.g., 5C3 = 5C2 = 10)
  • nPr = nCr × r!
  • nC0 = 1, nCn = 1

Important Formulas

n! = n × (n-1) × (n-2) × ... × 1

nPr = n! / (n-r)!

nCr = n! / [r! × (n-r)!]

When all n items are to be arranged: n! ways

When r items are identical among n: n! / (number of identical items!)

What to Write in Exam

For 3 marks - Difference between permutation and combination: Permutation is arrangement where order matters (e.g., passwords). Combination is selection where order doesn't matter (e.g., team selection). Formula: nPr = n!/(n-r)!, nCr = n!/[r!(n-r)!]. Example: Arranging 3 books from 5 is 5P3 = 60, selecting 3 from 5 is 5C3 = 10.

For 5 marks: Define factorial, permutation, and combination with formulas. Solve 2 numerical examples - one for permutation and one for combination. Explain when to use which (keywords: arrange/order = permutation, select/choose = combination).

For 10 marks: Full explanation with formulas, multiple solved examples, the difference table, and special cases (repetitions, restrictions). Include at least 3-4 different types of problems with complete solutions.

Memory Trick

"Permutation = Position matters, Combination = Choice only"

"P for Position, C for Choose"

Ask yourself: "Does changing the ORDER give a different result?" If YES → Permutation. If NO → Combination.

Quick calculation: nPr = n(n-1)(n-2)...(r terms). For 5P3 = 5×4×3 = 60 (just multiply 3 numbers starting from 5 going down).

Unit Summary (Quick Revision)

  • Factorial n! = n × (n-1) × ... × 1; 0! = 1
  • Permutation: Order matters. nPr = n!/(n-r)!
  • Combination: Order doesn't matter. nCr = n!/[r!(n-r)!]
  • Permutation = Arrangement, Combination = Selection
  • nPr = nCr × r!
  • nCr = nCn-r
  • Keywords: arrange/seating/password = P, choose/team/committee = C

Unit 7: Mathematical Logic

What is Mathematical Logic?

Mathematical logic is like the "rules of thinking" in mathematics. A proposition is simply a statement that can be either TRUE or FALSE (not both, not neither). For example, "The sun rises in the east" is TRUE. "2 + 2 = 5" is FALSE. But "Close the door" is NOT a proposition (it's a command, not true/false).

Types of Statements:

  • Tautology: Always TRUE (all T in final column). Example: p ∨ ¬p
  • Contradiction: Always FALSE (all F in final column). Example: p ∧ ¬p
  • Contingency: Sometimes true, sometimes false.

Logical Equivalence: Two statements are equivalent if they have the same truth table.

  • Commutative: p ∧ q ≡ q ∧ p
  • Associative: (p ∧ q) ∧ r ≡ p ∧ (q ∧ r)
  • Distributive: p ∧ (q ∨ r) ≡ (p ∧ q) ∨ (p ∧ r)
  • De Morgan's: ¬(p ∧ q) ≡ ¬p ∨ ¬q and ¬(p ∨ q) ≡ ¬p ∧ ¬q

Normal Forms:

  • DNF (Disjunctive Normal Form): OR of ANDs. Example: (p ∧ q) ∨ (¬p ∧ r)
  • CNF (Conjunctive Normal Form): AND of ORs. Example: (p ∨ q) ∧ (¬p ∨ r)

Important Formulas / Equivalences

  • ¬(¬p) ≡ p (Double negation)
  • p → q ≡ ¬p ∨ q (Implication to disjunction)
  • p ↔ q ≡ (p → q) ∧ (q → p)
  • ¬(p → q) ≡ p ∧ ¬q
  • De Morgan's: ¬(p ∧ q) ≡ ¬p ∨ ¬q

What to Write in Exam

For 3 marks: A proposition is a declarative statement that is either true or false. Examples: "5 > 3" (True), "2+2=5" (False). NOT propositions: questions, commands, opinions. The five logical connectives are AND(∧), OR(∨), NOT(¬), IMPLIES(→), IFF(↔).

For 5 marks: Explain AND, OR, NOT, IMPLIES with truth tables. Give real-life examples: AND = "I will go to the movie if I have money AND time" (both must be true). OR = "I will drink tea OR coffee" (at least one). NOT = "It is NOT raining" (opposite).

For 10 marks: Define proposition, explain all 5 connectives with truth tables, explain tautology/contradiction/contingency, prove De Morgan's laws using truth tables, explain DNF and CNF with examples.

Memory Trick

AND: Both must be true (like "AND" means "together")

OR: At least one true (like "OR" means "either is fine")

IMPLIES (p→q): Only FALSE when promise is broken (p=T, q=F). "A true statement cannot imply a false one."

Tautology vs Contradiction: Tautology = All True (T-tautology), Contradiction = All False (C-contradiction).

De Morgan's in Logic: Same as in sets! Break the bar, change the sign: ¬(p∧q) = ¬p∨¬q.

Unit Summary (Quick Revision)

  • Proposition = statement that is True or False
  • 5 connectives: AND(∧), OR(∨), NOT(¬), IMPLIES(→), IFF(↔)
  • AND: both true, OR: at least one true, NOT: opposite
  • p→q is false only when p=T and q=F
  • Tautology: always true, Contradiction: always false
  • De Morgan's: ¬(p∧q) = ¬p∨¬q, ¬(p∨q) = ¬p∧¬q
  • DNF = OR of ANDs, CNF = AND of ORs

Unit 8: Relations

What is a Relation?

A relation connects elements of one set to elements of another set (or the same set). Think of it like a "connection" or "link" between things. For example, if Set A = {Rahul, Priya} and Set B = {Maths, Science, English}, then "Rahul studies Maths" is a relation from A to B. A relation is a subset of A × B (Cartesian product).

Key Concepts

Cartesian Product A×B: All possible ordered pairs (a, b) where a ∈ A and b ∈ B.

A = {1,2}, B = {x,y} → A×B = {(1,x),(1,y),(2,x),(2,y)}

A Relation R from A to B is any subset of A×B.

R = {(1,x),(2,y)} is a relation from A to B

Types of Relations (on a set A to itself):

  • Reflexive: Every element relates to itself. (a,a) ∈ R for all a ∈ A.
    Example: "Equals" is reflexive because a = a for all a.
  • Symmetric: If a relates to b, then b also relates to a. If (a,b) ∈ R then (b,a) ∈ R.
    Example: "Is sibling of" is symmetric (if X is sibling of Y, then Y is sibling of X).
  • Transitive: If a relates to b and b relates to c, then a relates to c. If (a,b)∈R and (b,c)∈R then (a,c)∈R.
    Example: "Greater than" is transitive (if 5>3 and 3>1, then 5>1).
  • Anti-symmetric: If a relates to b and b relates to a, then a = b. If (a,b)∈R and (b,a)∈R then a = b.
    Example: "≤" is anti-symmetric.

Equivalence Relation: A relation that is Reflexive AND Symmetric AND Transitive (all three!).
Example: "Equals" (=) is an equivalence relation.

Partial Order: A relation that is Reflexive AND Anti-symmetric AND Transitive.
Example: "≤" (less than or equal) is a partial order.

Representations:

  • Arrow Diagram: Draw sets as boxes, arrows show relations
  • Matrix Form: Create a table with 1s and 0s. 1 = relation exists, 0 = no relation
  • Graph Form: Draw points (vertices) for elements, arrows for relations

Inverse Relation R-1: Reverse all pairs. If (a,b) ∈ R, then (b,a) ∈ R-1.

Composition (SοR): If (a,b) ∈ R and (b,c) ∈ S, then (a,c) ∈ SοR.

Important Formulas

If |A| = m and |B| = n, then |A×B| = m × n

Total possible relations from A to B = 2m×n

Total possible relations on set A (A to A) = 2n² where |A| = n

What to Write in Exam

For 3 marks: A relation R from set A to set B is a subset of the Cartesian product A×B. It connects elements of A to elements of B. Example: A={1,2,3}, R={(1,1),(2,2),(3,3),(1,2)} is a relation on A. The four properties are: Reflexive, Symmetric, Transitive, and Anti-symmetric.

For 5 marks: Define and explain each property with example: (1) Reflexive: every element relates to itself, (2) Symmetric: if aRb then bRa, (3) Transitive: if aRb and bRc then aRc, (4) Anti-symmetric: if aRb and bRa then a=b. An equivalence relation satisfies Reflexive + Symmetric + Transitive. Example: "=" on integers.

For 10 marks: Define relation, Cartesian product, all four properties with examples and counter-examples, equivalence relation, partial order, representations (arrow, matrix, graph), inverse relation, and composition of relations.

Memory Trick

Properties: "RSTA" - Reflexive, Symmetric, Transitive, Anti-symmetric

Equivalence = R + S + T (Remember: "ReST" - Rest is Equivalence!)

Partial Order = R + A + T (Remember: "RAT" - Partial order is like a RAT!)

Reflexive: "Everyone loves themselves" - each element relates to itself.

Symmetric: "If I'm your friend, you're my friend" - goes both ways.

Transitive: "Friend of my friend is my friend" - chains work.

  • Cartesian product A×B = all ordered pairs
  • Reflexive: every element relates to itself
  • Symmetric: if aRb then bRa
  • Transitive: if aRb and bRc then aRc

Unit 9: Functions

What is a Function?

A function is a special type of relation where every element in set A maps to exactly ONE element in set B. Think of it like a vending machine: you put in one coin (input), you get exactly one item (output). You can't put in one coin and get two items! If f is a function from A to B, we write f: A → B.

Key Concepts

Domain: Set A (the input set - all possible inputs)

Codomain: Set B (the set where outputs come from)

Range: The actual set of outputs (subset of codomain)

If f: {1,2,3} → {a,b,c,d} defined by f(1)=a, f(2)=b, f(3)=c
Domain = {1,2,3}, Codomain = {a,b,c,d}, Range = {a,b,c}

Types of Functions:

  • One-to-One (Injective): Different inputs give different outputs. No two elements of A map to the same element of B.
    Example: f(x) = 2x is injective (f(1)=2, f(2)=4, f(3)=6 - all different)
  • Onto (Surjective): Every element of B is used as an output. Range = Codomain.
    Example: f: {1,2} → {a,b} with f(1)=a, f(2)=b is onto.
  • One-to-One and Onto (Bijective): Both injective AND surjective. Every element of B is used exactly once.
    Example: f: {1,2,3} → {a,b,c} with f(1)=a, f(2)=b, f(3)=c is bijective.

Inverse Function f-1: Exists ONLY if f is bijective. It reverses the mapping: if f(a) = b, then f-1(b) = a.

Composition of Functions: (f ο g)(x) = f(g(x)). Apply g first, then apply f to the result.

If f(x) = x+1 and g(x) = 2x, then (fοg)(x) = f(g(x)) = f(2x) = 2x+1
And (gοf)(x) = g(f(x)) = g(x+1) = 2(x+1) = 2x+2 ≠ fοg (composition is NOT commutative!)

Real-valued Functions:

  • Constant function: f(x) = c (always same value). Example: f(x) = 5
  • Identity function: f(x) = x (output = input)
  • Polynomial function: f(x) = anxn + ... + a1x + a0
  • Rational function: f(x) = p(x)/q(x) where q(x) ≠ 0
  • Modulus function: f(x) = |x| (always positive). |−3| = 3, |5| = 5

Important Formulas

Composition: (f ο g)(x) = f(g(x))

Inverse: If f(a) = b, then f-1(b) = a

Modulus: |x| = x if x ≥ 0, |x| = -x if x < 0

What to Write in Exam

For 3 marks: A function f: A→B maps each element of A to exactly one element of B. Domain = set of inputs, Range = set of outputs. Types: One-to-one (different inputs → different outputs), Onto (every element of B is an output), Bijective (both one-to-one and onto).

For 5 marks: Define function, domain, codomain, range. Explain three types with examples: Injective (f(x)=2x - each input gives unique output), Surjective (f(x)=x on same domain and codomain - all outputs covered), Bijective (f(x)=x+1 on integers - both properties). Explain that inverse exists only for bijective functions.

For 10 marks: Full explanation with all types, composition with examples, inverse function, and real-valued functions (constant, identity, polynomial, rational, modulus) with graphs described.

Memory Trick

One-to-One (Injective): "One input → One unique output, no sharing!"

Onto (Surjective): "ONTO = ALL of B is covered!"

Bijective: "Perfect matching" - like arranging seats: each person gets exactly one unique seat.

Composition (fοg): "g first, then f" - read right to left! Like f(g(x)) - the inside function runs first.

Inverse: "Only Bijective functions can have inverses" - because only they can be reversed without confusion.

Unit Summary (Quick Revision)

  • Function: each input maps to exactly one output
  • Domain = inputs, Codomain = possible outputs, Range = actual outputs
  • Injective (one-to-one): different inputs → different outputs
  • Surjective (onto): Range = Codomain
  • Bijective: both injective and surjective
  • Inverse exists only for bijective functions
  • Composition: (fοg)(x) = f(g(x)), g runs first
  • Types: Constant, Identity, Polynomial, Rational, Modulus

Unit 10: Vectors

What is a Vector?

A vector is a quantity that has BOTH magnitude (size/amount) AND direction. Think of wind: "30 km/h towards North" - it has a speed (30 km/h) and a direction (North). A scalar has only magnitude, like temperature (30°C - no direction!).

Key Concepts

Representation: A 3D vector is written as v = ai + bj + ck where a, b, c are numbers and i, j, k are unit vectors along x, y, z axes.

v = 3i + 4j + 5k means: 3 units along x-axis, 4 along y-axis, 5 along z-axis

Magnitude (Length):

|v| = √(a² + b² + c²)

|v| = |3i + 4j + 5k| = √(9 + 16 + 25) = √50 = 5√2

Vector Operations:

  • Addition: Add corresponding components. (a1i + b1j + c1k) + (a2i + b2j + c2k) = (a1+a2)i + (b1+b2)j + (c1+c2)k
  • Subtraction: Subtract corresponding components.
  • Scalar Multiplication: Multiply each component by the scalar. k(ai + bj + ck) = (ka)i + (kb)j + (kc)k
(2i + 3j) + (4i + j) = 6i + 4j   |   3(2i + j) = 6i + 3j

Dot Product (Scalar Product): Results in a NUMBER (scalar).

A·B = |A||B|cosθ = a1b1 + a2b2 + a3b3

A = 2i + 3j + k, B = i + 4j + 2k
A·B = 2(1) + 3(4) + 1(2) = 2 + 12 + 2 = 16

If A·B = 0, the vectors are perpendicular (angle = 90°).

Cross Product (Vector Product): Results in a VECTOR perpendicular to both A and B.

A×B = |A||B|sinθ n̂ (where n̂ is the unit vector perpendicular to both)

Calculated using determinant method for 3D vectors.

Unit Vector: A vector with magnitude 1 in the direction of a.

â = a / |a|

Unit vector of 3i + 4j = (3i + 4j) / √(9+16) = (3i + 4j)/5 = (3/5)i + (4/5)j

Important Formulas

Magnitude: |v| = √(a² + b² + c²)

Dot Product: A·B = a1b1 + a2b2 + a3b3 = |A||B|cosθ

Cross Product: |A×B| = |A||B|sinθ

Angle between vectors: cosθ = (A·B) / (|A||B|)

Unit vector: â = a/|a|

What to Write in Exam

For 3 marks: A vector has both magnitude and direction (e.g., velocity, force). A scalar has only magnitude (e.g., mass, temperature). Vectors are represented as ai + bj + ck. The magnitude is |v| = √(a²+b²+c²). Two vectors are equal if they have the same magnitude and direction.

  • Vector: has magnitude AND direction. Scalar: magnitude only
  • Written as ai + bj + ck in 3D
  • Magnitude: |v| = √(a²+b²+c²)
  • Addition/Subtraction: component-wise

Unit 11: Matrices and Determinants

What is a Matrix?

A matrix is a rectangular arrangement of numbers in rows and columns, like a spreadsheet or a table. It's written inside square brackets [ ]. The size is "rows × columns". For example, a 2×3 matrix has 2 rows and 3 columns. Matrices are used everywhere in computers - graphics, AI, data processing!

Key Concepts

Types of Matrices:

  • Row Matrix: Only 1 row. [1 2 3] (1×3)
  • Column Matrix: Only 1 column.
  • Square Matrix: Same number of rows and columns (n×n).
  • Diagonal Matrix: Square matrix with zeros except on the main diagonal.
  • Identity Matrix (I): Diagonal matrix with all 1s on diagonal. A×I = I×A = A.
  • Null/Zero Matrix (O): All elements are 0.
  • Symmetric Matrix: A = AT (matrix equals its transpose)
  • Skew-symmetric Matrix: A = -AT
  • Singular: |A| = 0 (determinant is zero)
  • Non-singular: |A| ≠ 0

Matrix Operations:

  • Addition: Add corresponding elements. Both matrices must be the SAME SIZE.
  • Subtraction: Subtract corresponding elements. Same size required.
  • Scalar Multiplication: Multiply every element by the number.
  • Matrix Multiplication: Number of columns of A must equal number of rows of B. Result has rows of A and columns of B.
Matrix Multiplication Example:
A = [1 2; 3 4]   B = [5 6; 7 8]
A×B = [1×5+2×7   1×6+2×8; 3×5+4×7   3×6+4×8]
= [19 22; 43 50]

Transpose (AT): Rows become columns, columns become rows.

If A = [1 2 3; 4 5 6], then AT = [1 4; 2 5; 3 6]

Determinant:

For 2×2: |[a b; c d]| = ad - bc

|[3 2; 5 4]| = 3×4 - 2×5 = 12 - 10 = 2

For 3×3: Expand along any row/column using cofactors.

|[1 2 3; 0 4 5; 1 0 6]| (expand along row 1)
= 1(4×6 - 5×0) - 2(0×6 - 5×1) + 3(0×0 - 4×1)
= 1(24) - 2(-5) + 3(-4) = 24 + 10 - 12 = 22

Minor Mij: Determinant of the matrix after removing row i and column j.

Cofactor Cij: Cij = (-1)i+j × Mij

Adjoint: Transpose of the cofactor matrix.

Inverse: A-1 = (1/|A|) × Adj(A)   (exists only if |A| ≠ 0)

Important Formulas

|A| for 2×2: ad - bc

Cofactor: Cij = (-1)i+j × Mij

Adjoint = Transpose of Cofactor Matrix

A-1 = (1/|A|) × Adj(A)

A × A-1 = A-1 × A = I (Identity Matrix)

(AB)T = BTAT (reverse order!)

|AB| = |A| × |B|

What to Write in Exam

For 3 marks: A matrix is a rectangular array of numbers in rows and columns. Types include: row, column, square, diagonal, identity (I), zero, symmetric, and skew-symmetric. The determinant of a 2×2 matrix [a b; c d] is ad-bc. A matrix is singular if its determinant is 0.

Unit 13: System of Linear Equations

What is a System of Linear Equations?

A linear equation is an equation where all variables have power 1 (no x², x³, etc.). For example, 2x + 3y = 7 is linear. A system means multiple equations together that need to be solved at the same time. For example: x + y = 5 and x - y = 1. The solution is the values of x and y that make BOTH equations true at the same time.

Key Concepts

Types of Systems:

  • Homogeneous: All constant terms are 0. Example: 2x + 3y = 0, x - y = 0. Always has the trivial solution x=0, y=0.
  • Non-homogeneous: At least one constant is non-zero. Example: 2x + 3y = 5.

Solution Types:

  • Unique solution: Exactly one answer (lines intersect at one point). System is consistent.
  • Infinite solutions: Many answers (lines overlap completely). System is consistent.
  • No solution: No answer exists (lines are parallel, never meet). System is inconsistent.

Matrix Form: AX = B where A = coefficient matrix, X = variable matrix, B = constant matrix.

2x + 3y = 5 and x - y = 1 can be written as:
[2 3; 1 -1] [x; y] = [5; 1]    Here A=[2 3; 1 -1], X=[x; y], B=[5; 1]

Cramer's Rule (for solving systems using determinants):

For 2 variables: x = |A1|/|A|, y = |A2|/|A|

Where A1 = A with column 1 replaced by B, A2 = A with column 2 replaced by B.

Solve: 2x + 3y = 5, x - y = 1
A = [2 3; 1 -1], |A| = 2(-1) - 3(1) = -5
A1 = [5 3; 1 -1], |A1| = 5(-1) - 3(1) = -8
A2 = [2 5; 1 1], |A2| = 2(1) - 5(1) = -3
x = |A1|/|A| = -8/-5 = 8/5, y = |A2|/|A| = -3/-5 = 3/5

For 3 variables: x = |A1|/|A|, y = |A2|/|A|, z = |A3|/|A|

Where Ai replaces the i-th column of A with B.

Important: If |A| = 0, Cramer's Rule cannot be used (system has no unique solution).

Important Formulas

Cramer's Rule: xi = |Ai| / |A|

Ai = Matrix A with column i replaced by constant matrix B

If |A| ≠ 0: Unique solution exists (consistent)

If |A| = 0 and all |Ai| = 0: Infinite solutions (consistent)

If |A| = 0 and at least one |Ai| ≠ 0: No solution (inconsistent)

What to Write in Exam

For 3 marks: A system of linear equations is a set of equations with the same variables, all with degree 1. It can be: (1) Consistent with unique solution (lines meet at one point), (2) Consistent with infinite solutions (same line), (3) Inconsistent with no solution (parallel lines). In matrix form: AX = B.

For 5 marks: Explain Cramer's Rule with a complete 2-variable example. Show how to form matrices A, A1, A2, calculate determinants, and find x and y. Mention that it works only when |A| ≠ 0.

For 10 marks: Define system of linear equations, homogeneous vs non-homogeneous, consistent vs inconsistent, matrix form, Cramer's Rule for both 2 and 3 variables with complete solved examples for each.

Memory Trick

Cramer's Rule: "Replace the column, find the ratio!" Replace column 1 with B to get x, column 2 with B to get y, column 3 with B to get z.

x = |A1|/|A|: "1 for x (1st variable = 1st column)"

Consistent vs Inconsistent: Consistent = "CAN solve", Inconsistent = "CAN'T solve"

|A| = 0: "Zero determinant means Cramer's Rule FAILS - don't use it!"

Unit Summary (Quick Revision)

  • Linear equation: all variables have power 1
  • System: multiple equations solved together
  • Homogeneous: all constants = 0, Non-homogeneous: at least one constant ≠ 0
  • Matrix form: AX = B
  • Three cases: Unique, Infinite, No solution
  • Cramer's Rule: xi = |Ai|/|A| (replace column i with B)
  • Works only when |A| ≠ 0
  • |A| = 0 means no unique solution

Unit 14: Polynomials

What is a Polynomial?

A polynomial is a mathematical expression made by adding/subtracting terms with variables raised to whole number powers (0, 1, 2, 3...). Think of it as a "many-term" expression. Examples: 3x² + 2x + 1, x³ - 5x, 7 (yes, a single number is also a polynomial!). The highest power tells you the "degree" of the polynomial.

Key Concepts

General Form: p(x) = anxn + an-1xn-1 + ... + a1x + a0

where an, an-1, ..., a0 are numbers (coefficients) and an ≠ 0.

Types by Degree:

DegreeNameExample
0Constant polynomialp(x) = 5
1Linear polynomialp(x) = 2x + 3
2Quadratic polynomialp(x) = x² + 3x + 2
3Cubic polynomialp(x) = x³ - 2x + 1

Operations on Polynomials:

  • Addition: Add coefficients of same-degree terms.
  • Subtraction: Subtract coefficients of same-degree terms.
  • Multiplication: Multiply each term of first by each term of second, combine like terms.
(2x² + 3x + 1) + (x² - 2x + 4) = 3x² + x + 5
(x + 2)(x + 3) = x² + 3x + 2x + 6 = x² + 5x + 6

Roots/Zeros of a Polynomial:

A root is a value of x that makes p(x) = 0. If p(2) = 0, then x = 2 is a root.

p(x) = x² - 5x + 6 = (x-2)(x-3). Roots are x = 2 and x = 3.
Check: p(2) = 4 - 10 + 6 = 0 ✓   p(3) = 9 - 15 + 6 = 0 ✓

Remainder Theorem: When p(x) is divided by (x - a), the remainder = p(a).

p(x) = x³ + 2x - 1, divided by (x - 1)
Remainder = p(1) = 1 + 2 - 1 = 2 (no need to do long division!)

Factor Theorem: (x - a) is a factor of p(x) if and only if p(a) = 0.

Is (x-2) a factor of x² - 5x + 6? Check: p(2) = 4 - 10 + 6 = 0. Yes! It's a factor.

Important Formulas

Degree = highest power of x

Remainder Theorem: Remainder of p(x) ÷ (x-a) = p(a)

Factor Theorem: (x-a) is a factor of p(x) ↔ p(a) = 0

Quadratic formula: x = [-b ± √(b² - 4ac)] / 2a (for ax² + bx + c = 0)

Sum of roots = -b/a, Product of roots = c/a (for quadratic)

A polynomial of degree n has at most n roots.

What to Write in Exam

For 3 marks: A polynomial is an expression like anxn + ... + a1x + a0 where powers are non-negative integers. The degree is the highest power. Types: constant (degree 0), linear (1), quadratic (2), cubic (3). Example: x² + 3x + 2 is a quadratic polynomial with degree 2.

For 5 marks: Define polynomial, degree, and types. Explain Remainder Theorem with example: "When p(x) is divided by (x-a), remainder = p(a)." Explain Factor Theorem: "(x-a) is a factor if p(a) = 0." Solve one example of each.

For 10 marks: Full coverage: definition, types, operations (addition, subtraction, multiplication with examples), roots/zeros, Remainder Theorem with proof idea and example, Factor Theorem with proof idea and example, and quadratic formula. Include 3-4 solved examples.

Memory Trick

Remainder Theorem: "Just PLUG IN the number!" To find remainder when dividing by (x-a), simply calculate p(a).

Factor Theorem: "If p(a) = 0, then (x-a) is a FACTOR" - zero remainder means it divides perfectly.

Types by degree: "0-C, 1-L, 2-Q, 3-C" = Constant, Linear, Quadratic, Cubic.

Quadratic formula: "Minus b, plus or minus, square root of b-squared minus 4ac, all over 2a"

Unit Summary (Quick Revision)

  • Polynomial: expression with variables raised to whole number powers
  • Degree: highest power of x
  • Types: Constant(0), Linear(1), Quadratic(2), Cubic(3)
  • Operations: add/subtract same-degree terms, multiply all combinations
  • Root/Zero: value of x where p(x) = 0
  • Remainder Theorem: remainder of p(x)÷(x-a) = p(a)
  • Factor Theorem: (x-a) is a factor if p(a) = 0
  • Quadratic formula: x = [-b ± √(b²-4ac)] / 2a

Unit 15: Introduction to Graph Theory

What is Graph Theory?

In everyday life, a "graph" means a chart or diagram. But in mathematics, a graph is a collection of points (called vertices) connected by lines (called edges). Think of a social network: people are vertices, friendships are edges. Or a road map: cities are vertices, roads are edges. Graph theory studies these connections!

Key Concepts

Graph G = (V, E) where V = set of vertices (points), E = set of edges (lines connecting points).

G = ({A, B, C}, {(A,B), (B,C), (A,C)}) has 3 vertices A, B, C and 3 edges connecting them.

Types of Graphs:

  • Undirected Graph: Edges have no direction. If A-B is an edge, you can go from A to B or B to A.
  • Directed Graph (Digraph): Edges have arrows showing direction. A→B means you can only go from A to B.
  • Simple Graph: No loops (edge from vertex to itself) and no multiple edges between same pair.
  • Multi Graph: May have multiple edges between same pair of vertices.
  • Complete Graph (Kn): Every vertex is connected to every other vertex. Has n(n-1)/2 edges.
  • Null Graph: Vertices exist but no edges at all.

Degree of a Vertex: Number of edges connected to it.

In a triangle (3 vertices, 3 edges), each vertex has degree 2.

Handshaking Lemma: Sum of all degrees = 2 × (number of edges). (Because each edge is counted twice - once at each end.)

Path: A sequence of edges connecting vertices without repeating any edge.

Circuit/Cycle: A path that starts and ends at the same vertex.

Euler Graph: Contains an Euler circuit - a path that visits every edge exactly once and returns to the starting point.

Condition: An Euler circuit exists if and only if EVERY vertex has an EVEN degree.

A triangle (all degrees = 2, which is even) has an Euler circuit: A→B→C→A.

Hamiltonian Graph: Contains a Hamiltonian circuit - a path that visits every vertex exactly once and returns to the starting point.

In a complete graph K4, you can visit all 4 vertices and return to start.

Tree: A connected graph with NO cycles. Has exactly n-1 edges for n vertices.

A family tree, file directory structure, or organization chart are examples of trees.

Matrix Representations:

  • Adjacency Matrix: A square matrix where entry [i][j] = number of edges between vertex i and vertex j.
  • Incidence Matrix: Rows = vertices, Columns = edges. Entry = 1 if vertex is connected to that edge, 0 otherwise.
For graph with 2 vertices (A, B) and 1 edge between them:
Adjacency Matrix = [0 1; 1 0] (A-B exists, no self-loops)
Incidence Matrix = [1; 1] (both vertices connected to edge 1)

Important Formulas

Sum of degrees = 2 × |E| (Handshaking Lemma)

Complete graph Kn: Number of edges = n(n-1)/2

Tree with n vertices: Number of edges = n - 1

Euler circuit exists: All vertices have even degree

Adjacency matrix is always square (n×n for n vertices)

What to Write in Exam

For 3 marks: A graph G = (V, E) consists of vertices (points) and edges (lines). Types: directed (edges have arrows), undirected (no arrows), simple (no loops/multiple edges), complete (all connected), null (no edges). The degree of a vertex is the number of edges connected to it.

For 5 marks: Define graph, explain types with small examples. Define degree and state the Handshaking Lemma (sum of degrees = 2×|E|). Define path and circuit. Explain Euler graph condition (all even degrees) with example.

For 10 marks: Full coverage: definition, all graph types with examples, degree, Handshaking Lemma with proof idea, path, circuit, Euler graph (with condition and example), Hamiltonian graph (with example), Tree (definition and properties), and matrix representations (adjacency and incidence) with examples.

Memory Trick

Graph components: "V for Vertices (points), E for Edges (lines)"

Complete graph edges: "n(n-1)/2" - think of it as "everyone shakes hands with everyone else" (like nC2).

Euler = Edges, Hamiltonian = Vertices: Euler visits every EDGE once, Hamiltonian visits every VERTEX once. "E for Edge, H for Hub (vertex)"

Euler circuit condition: "ALL EVEN = Euler!" Every vertex must have even degree.

Tree: "Connected + No cycles = Tree" - like a real tree with branches that never loop back.

Adjacency Matrix: "Who is next to whom?" Incidence Matrix: "Which edges touch which vertices?"

Unit Summary (Quick Revision)

  • Graph G = (V, E): vertices and edges
  • Types: Directed, Undirected, Simple, Multi, Complete, Null
  • Degree = number of edges at a vertex
  • Handshaking Lemma: sum of degrees = 2 × |E|
  • Complete graph Kn has n(n-1)/2 edges
  • Euler circuit: visits every edge once; all vertices must have even degree
  • Hamiltonian circuit: visits every vertex once
  • Tree: connected, no cycles, n-1 edges for n vertices
  • Adjacency matrix: n×n, shows which vertices are connected
  • Incidence matrix: vertices × edges, shows which vertex connects to which edge
